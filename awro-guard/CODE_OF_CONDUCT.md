# Code of Conduct

## Our Commitment

We, as contributors and maintainers of **AeroGuard AI**, are committed to fostering a welcoming, professional, and respectful environment for everyone participating in this project.

Our goal is to build an innovative AI-powered airport surveillance platform while encouraging collaboration, knowledge sharing, and mutual respect.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and professional.
- Accepting constructive feedback.
- Helping teammates solve technical problems.
- Sharing knowledge openly.
- Communicating clearly and politely.
- Respecting different opinions and experiences.
- Writing clean, maintainable, and well-documented code.
- Reviewing code objectively and professionally.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination of any kind.
- Personal attacks or offensive language.
- Trolling or intentionally disrupting discussions.
- Publishing confidential information.
- Uploading malicious code.
- Pushing unreviewed code directly to protected branches.
- Ignoring project guidelines and workflows.
- Claiming credit for someone else's work.

---

# Collaboration Guidelines

To maintain project quality:

- Always work on a separate feature branch.
- Submit Pull Requests for review.
- Wait for approval before merging.
- Keep commits meaningful and descriptive.
- Test your code before submitting.

---

# Communication

Please communicate respectfully during:

- Pull Request reviews
- Code discussions
- Issue reporting
- Feature planning
- Team meetings

Constructive criticism is encouraged.

Personal criticism is not.

---

# Code Quality

Every contributor should strive to:

- Write clean code.
- Follow project architecture.
- Avoid unnecessary complexity.
- Maintain consistency.
- Document important functionality.
- Keep the project stable.

---

# Security Responsibility

Never commit:

- Passwords
- API Keys
- JWT Tokens
- Database Credentials
- Environment Variables
- Sensitive Personal Information

Always use environment variables for secrets.

---

# AI Development Guidelines

When modifying AI components:

- Preserve detection accuracy.
- Avoid unnecessary performance degradation.
- Test inference before submitting.
- Maintain compatibility with existing AI models.
- Document any AI-related changes.

---

# Project Workflow

The official workflow is:

1. Create a feature branch.
2. Implement the feature.
3. Test your changes.
4. Push your branch.
5. Open a Pull Request.
6. Wait for review.
7. Merge only after approval.

---

# Reporting Problems

If you discover:

- Bugs
- Security vulnerabilities
- Performance issues
- Incorrect AI behavior

Please report them through GitHub Issues with enough information to reproduce the problem.

---

# Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

They may:

- Request changes.
- Reject Pull Requests.
- Remove inappropriate content.
- Restrict repository access in severe cases.

---

# Project Vision

AeroGuard AI aims to become a reliable, scalable, and intelligent surveillance platform for airport security.

Every contribution should support this vision by improving:

- Security
- Reliability
- Performance
- Maintainability
- Scalability
- User Experience

---

# Thank You

Thank you for contributing to **AeroGuard AI**.

Together, we are building a smarter, safer, and more intelligent future for airport surveillance.
